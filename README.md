# Babe Jiu Jitsu — versões

Instaladores do aplicativo Babe Jiu Jitsu, usados pela atualização automática.
Este repositório guarda só os arquivos de cada versão (Setup.exe, .nupkg e RELEASES), nas Releases; o código-fonte é privado.

Para instalar em um computador novo, baixe o `Setup.exe` da versão mais recente em Releases.
